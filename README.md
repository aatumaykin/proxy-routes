# proxy-routes

Список доменов, которые нужно маршрутизировать через прокси-выход. Один домен
на строку. Список — единственный источник истины: клиенты (прокси-клиенты,
маршрутизаторы) подтягивают `custom-proxy.txt` и строят правила из него.

## Использование

- Файл: [`custom-proxy.txt`](custom-proxy.txt) — по одному домену на строку.
- Ссылка для клиентов: `https://raw.githubusercontent.com/aatumaykin/proxy-routes/main/custom-proxy.txt`
- Комментарии — строки, начинающиеся с `#`; пустые строки игнорируются.

## Добавить домен

Добавь строку с доменом в `custom-proxy.txt` и закоммить. Клиенты подхватят
на следующем обновлении.
